# Senior Project Log

Use this file or a shared document to track accountability.

## Weekly entry template

```text
Week:
Owner:
Work completed:
Why it mattered:
How it was implemented:
Evidence:
PRs:
Issues closed:
Tests/evals:
Problems encountered:
Decisions made:
Next week:
What I can explain in defense:
```

## Rules

- Every teammate must have traceable PRs or review contributions.
- Every meaningful decision must be linked to an issue, PR, ADR, or weekly log entry.
- Avoid “I helped” as evidence. Use concrete artifacts.
