# Atlas UI System Prototype

Status: rejected exploration.

This static prototype is not the accepted Atlas visual direction.
Do not use it as production UI guidance.
It is kept only as a record of layout constraints, overflow checks, and failure modes from the first design pass.

The next accepted design artifact must pass `docs/architecture/ui-quality-bar.md`.

```bash
open docs/prototypes/atlas-ui-system/index.html
```

- Foundation tokens.
- Layout measurements for margins, padding, heights, widths, and breakpoints.
- Overflow proof rows for long source names, file names, URLs, and inspector values.
- Component states.
- Today Command Center.

Design invariants:

- Dark-first, dense, calm, and source-grounded.
- Structured product surfaces first.
- Persistent AI composer without replacing the app.
- Right inspector as the default context surface.
- Visibility, provenance, confidence, citations, redaction, and action risk are visible.
